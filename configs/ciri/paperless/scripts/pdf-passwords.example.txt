# Passwords tried against encrypted PDFs during paperless ingest, in order.
# Copy to pdf-passwords.txt next to this file, on the VM only:
#
#   install -m 600 pdf-passwords.example.txt /data/stacks/paperless/scripts/pdf-passwords.txt
#
# The real file is git-ignored and must stay mode 600, owned by uid 1000
# (host user `ciri`) so the paperless worker can read it. It is mounted
# read-only into the container.
#
# One password per line. Blank lines and lines starting with # are skipped.
# Leading/trailing spaces are significant — they are part of the password.
# There is no per-file mapping: every listed password is tried against every
# encrypted PDF until one opens it, so a handful of lines is fine and a
# thousand would be slow.
#
# Files with only an OWNER password (restrict printing/copying, but open
# without prompting) need no entry — the hook tries the empty password first.
#
# For a one-off whose password is not worth storing here, upload it as
# NAME__pw=THEPASSWORD.pdf instead. Note the suffix stays in the document
# title, so rename the title in the UI afterwards.
