# Proposal 010 — execution checklist (for the agent running it)

Companion to [010-bank-alerts-to-sure.md](010-bank-alerts-to-sure.md), which
holds the design and the reasoning. This file is the **step ladder**: one
step at a time, each with a verifiable goal. Do not start a step until the
previous one's *Verify* passed. The agent never runs a state-changing
command on the lab, the phone, Gmail, Sure or n8n — it hands the command
over, then verifies read-only. Record what each Verify actually returned in
the "As-built deviations" section of the proposal as you go.

Legend: **Human** = the user does it; **Agent** = the agent may do it
(read-only, or on the Mac inside the repo).
